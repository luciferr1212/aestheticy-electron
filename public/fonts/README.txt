Fonts
=====
Bundled (works offline, nothing to do):
  Inter + Inter Display (.woff, Latin/Latin-Ext/Cyrillic/Greek subsets) - SIL Open Font License 1.1,
  see Inter-LICENSE.txt. It is the closest open-source typeface to Apple's SF Pro.
  Arabic and other scripts fall back to Segoe UI / Tahoma, which ship with Windows.

Optional - the exact Apple Music font (SF Pro):
  Apple's license does not allow redistributing SF Pro inside third-party apps, so it is not included.
  If you own/install it, Aestheticy uses it automatically:
    - install SF Pro on the PC (Apple: https://developer.apple.com/fonts/), OR
    - convert the weights to .woff2 and drop them here with these exact names, then rebuild:
        SF-Pro-Text-Regular.woff2  SF-Pro-Text-Medium.woff2  SF-Pro-Text-Semibold.woff2  SF-Pro-Text-Bold.woff2
        SF-Pro-Display-Regular.woff2 SF-Pro-Display-Medium.woff2 SF-Pro-Display-Semibold.woff2 SF-Pro-Display-Bold.woff2
